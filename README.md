# react-offscreen-webgl

Render WebGL fragment shaders in React with an OffscreenCanvas and a shared Web Worker.

> [!WARNING]
> This project is alpha software. The API may change before a stable release.

```sh
npm install react-offscreen-webgl
```

React 17 or later is required. See the [documentation](https://tomaspietravallo.github.io/react-offscreen-webgl/) for the API, examples, and browser requirements, and [GitHub Releases](https://github.com/tomaspietravallo/react-offscreen-webgl/releases) for updates. The documentation source is also available in [docs](./docs/src/pages/index.mdx).
