## A little more room to render.

Each component creates a canvas in the DOM. A shared worker renders the shaders using one WebGL context on an `OffscreenCanvas`, then transfers frames as `ImageBitmap`s to the component canvases. Each component has its own shaders, uniforms, frame rate, and buffers.

<div className="feature-grid"><div><span>01</span><h3>Off the main thread</h3><p>The render loop runs in a worker, leaving the main thread free for your interface.</p></div><div><span>02</span><h3>Made for React</h3><p>Use a component and pass shader uniforms as props.</p></div><div><span>03</span><h3>One shared context</h3><p>Multiple canvases share a WebGL context, with frame transfer and memory costs.</p></div></div>
</section>

<section id="installation">
<div className="section-number">02 / SETUP</div>

## Installation

Install the package in a React project. React 17 or later is required.

```bash
npm install react-offscreen-webgl
```

The package is alpha software and its API may change. The browser must support Web Workers, OffscreenCanvas, WebGL, and `ImageBitmapRenderingContext`.

<div className="section-number">03 / FIRST RENDER</div>

## Quick start

Give the component a sized parent and a GLSL fragment shader. The canvas fills its parent.

```tsx
import { OffscreenWebGL } from 'react-offscreen-webgl';

const shader = `
  precision highp float;
  uniform vec2 u_resolution;

  void main() {
    vec2 uv = gl_FragCoord.xy / u_resolution;
    gl_FragColor = vec4(uv.x, uv.y, 0.0, 1.0);
  }
`;

export default function App() {
	return (
		<div style={{ width: 400, height: 400 }}>
			<OffscreenWebGL fragmentShader={shader} />
		</div>
	);
}
```

You can also load a shader with `fragmentShaderURL`. URL paths beginning with `/` resolve from the site origin, so include your base path when deploying under a subdirectory. Shader and URL props are read during initialization; remount the component to replace them.

## Props reference

<div className="table-wrap">

| Prop                    | Type                   | Default / purpose                                                       |
| ----------------------- | ---------------------- | ----------------------------------------------------------------------- |
| `fragmentShader`        | `string \| string[][]` | Built-in UV gradient; inline fragment source or shader groups.          |
| `fragmentShaderURL`     | `string \| string[][]` | Fetch fragment source from URL(s); takes precedence over inline source. |
| `vertexShader`          | `string`               | Built-in passthrough vertex shader.                                     |
| `vertexShaderURL`       | `string`               | Fetch vertex source; takes precedence over inline source.               |
| `refreshRate`           | `number`               | Render loop frequency in frames per second; default `30`.               |
| `disableResizeObserver` | `boolean`              | Default `false`; disables automatic canvas resizing.                    |
| `u_<name>`              | `number \| number[]`   | Float or float vector uniform.                                          |
| `f_<name>`              | function               | Run a callback in the worker; names containing `each` run every frame.  |

</div>

<section id="uniforms">

## Uniforms

Pass a number for a float, or an array of two, three, or four numbers for a vector. The component sets `u_resolution` to the canvas pixel dimensions and updates it on resize.

```tsx
<OffscreenWebGL fragmentShader={shader} u_intensity={0.8} u_offset={[0.5, 0.25]} />
```

</section>

<section id="callbacks">
<div className="section-number">06 / ANIMATION</div>

## Worker callbacks

Callbacks receive the manager, frame count, and elapsed time in milliseconds. Call `paintCanvas()` to render a frame. The live example updates a time uniform this way.

```tsx
<OffscreenWebGL
	fragmentShader={shader}
	f_each_animate={(manager, frame, time) => {
		manager.updateUniform('u_time', time / 1000);
		manager.paintCanvas();
	}}
/>
```

<div className="callout"><strong>Keep callbacks self-contained.</strong> Functions are serialized and evaluated in the worker, so they cannot capture variables from their surrounding scope. Pass values through uniforms instead.</div>
</section>

<section id="multipass">
<div className="section-number">07 / BEYOND ONE SHADER</div>

## Multi-pass rendering

Pass nested arrays to `fragmentShader` or `fragmentShaderURL` to configure shader groups. Shaders within a group ping-pong through framebuffer objects; the final group renders to the canvas. All passes share the vertex shader.

```tsx
<OffscreenWebGL fragmentShader={[[firstPass, secondPass], [finalPass]]} />
```

</section>

<section id="limitations">
<div className="section-number">08 / GOOD TO KNOW</div>

## Limitations

- The component is browser-only. In an SSR framework, load it on the client (for example, a dynamic import with SSR disabled).
- Worker callbacks share WebGL state; restore state you change so other components are unaffected.
- Media and camera textures are not yet supported. Frame transfers also add memory and copy costs.
- The library requires the browser features listed above. The example needs WebGL enabled to render.

For more detail and updates, see [GitHub](https://github.com/tomaspietravallo/react-offscreen-webgl) and [Releases](https://github.com/tomaspietravallo/react-offscreen-webgl/releases).
